## Audio

All game audio is **procedurally generated** at runtime using the Web Audio API.

- No audio files are distributed
- No external audio samples are used
- Sound effects are synthesized using oscillators, noise, and filters

## Visual Assets

All visual assets are **procedurally generated** at runtime using the HTML5 Canvas 2D API.

- No image files are distributed
- No 3D models are used
- All graphics are drawn programmatically (shapes, gradients, particles)
- No textures, sprites, or model files from any commercial game are included
