# Controls

## Movement

| Key | Action |
|---|---|
| **W** | Move forward |
| **S** | Move backward |
| **A** | Strafe left |
| **D** | Strafe right |
| **Shift (hold)** | Run |
| **Ctrl** or **C** | Crouch |

## Combat

| Input | Action |
|---|---|
| **Left Mouse Button** | Fire equipped weapon |
| **Right Mouse Button (hold)** | Aim mode (narrows FOV) |
| **R** | Reload weapon |
| **Q** | Use best healing item |

## Interaction

| Key | Action |
|---|---|
| **E** | Interact with objects, doors, documents, terminals |
| **F** | Use selected item |

## Menu Screens

| Key | Action |
|---|---|
| **Tab** | Toggle inventory screen |
| **M** | Toggle facility map |
| **Esc** | Pause / Resume |
| **1-5** | Quick-select items (future) |

## Settings

Configure in the Settings menu:

- **Mouse Sensitivity**: 0.1x to 2.0x
- **Invert Y-Axis**: Toggle
- **Hold to Aim**: Toggle (default: hold)
- **Hold to Sprint**: Toggle (default: hold)
- **Volume**: Master, Music, SFX
- **Subtitles**: On/Off, Size (small/medium/large)
- **Reduced Flashing**: Toggle
- **Camera Shake**: Toggle
- **Quality Preset**: Low / Medium / High

## Tips

- Ammunition is limited — conserve shots
- Running attracts enemies. Crouch to stay quiet
- Save only at terminals in safe rooms
- Examine items for hidden clues
- Combine items to create better equipment
- Read all documents for the full story and secret endings
